    一、延迟的基本概念与获取方法

    Propagation delay 是最常用的 delay。对于 tpdt_{pd}tpd​ 和 tcdt_{cd}tcd​ 来说，测量方法都是一样的：从输入跨过 VDD/2V_{DD}/2VDD​/2 开始，到输出跨过 VDD/2V_{DD}/2VDD​/2 结束。区别在于，像 NAND 门这种电路，同样是输出 0→10\to10→1 或 1→01\to01→0，不同输入端翻转、不同导通路径会导致延迟有快有慢。因此 tpdt_{pd}tpd​ 取最慢情况下的延迟，tcdt_{cd}tcd​ 取最快情况下的延迟。

    Factors Impacting Inverter Delay ｜ 影响反相器 delay 的因素

    1. Output load：输出负载越大，delay 越大：
    2. Device size：增大晶体管尺寸可以降低电阻：W↑⇒R↓W\uparrow \Rightarrow R\downarrowW↑⇒R↓，但会增加寄生电容：W↑⇒Cparasitic↑W\uparrow \Rightarrow C_{parasitic}\uparrowW↑⇒Cparasitic​↑，所以存在 trade-off。
    3. P/N ratio，PMOS 和 NMOS 的尺寸比例会影响上升延迟和下降延迟。PMOS 做大，上升更快，但它的扩散电容也变大，可能拖慢下降。
    4. Input slew：输入边沿越慢，输出延迟通常越大。因为输入慢时，PMOS 和 NMOS 同时导通的时间更长，并且还会带来更复杂的耦合效应。
    Device Size —— 晶体管尺寸对 delay 的影响

    随着尺寸因子 SSS 增大，delay 下降，但不是线性下降，而是逐渐趋于饱和。

    原因是：

    • 刚开始增大晶体管时，RRR 明显下降，所以 delay 降得快；
    • 后面继续增大时，晶体管自己的 intrinsic capacitance 寄生电容也变大；
    • self-loading effect 开始主导，所以 delay 不再明显下降。

    可以把总 delay 写成一个直观形式：t≈Req(Cload+Cparasitic)t \approx R_{eq}(C_{load}+C_{parasitic})t≈Req​(Cload​+Cparasitic​)，假设尺寸放大 SSS 倍：Req∼RSR_{eq}\sim \frac{R}{S}Req​∼SR​ Cparasitic∼SCC_{parasitic}\sim SCCparasitic​∼SC，所以：t∼RS(Cload+SC)t\sim \frac{R}{S}(C_{load}+SC)t∼SR​(Cload​+SC) 即 t∼RCloadS+RCt\sim \frac{RC_{load}}{S}+RCt∼SRCload​​+RC

    第一项会随着 SSS 增大而下降，但第二项不会消失。这就是为什么尺寸做大后 delay 下降会变慢。

    PMOS/NMOS Ratio —— PMOS/NMOS 比例

    固定 NMOS、增大 β=Wp/Wn\beta=W_p/W_nβ=Wp​/Wn​ 时，PMOS 上拉电阻减小，tpLHt_{pLH}tpLH​ 下降；但 PMOS 扩散电容增大，输出节点负载变大，NMOS 放电更慢，tpHLt_{pHL}tpHL​ 上升。因此平均延迟 tpt_ptp​ 随 β\betaβ 呈 U 形变化，存在最优宽度比。这个最优点不一定等于 tpLH=tpHLt_{pLH}=t_{pHL}tpLH​=tpHL​ 的平衡点。

    Input Slew ｜ 输入边沿对 delay 的影响

    讨论输入 slew，也就是输入信号的上升/下降时间。

    对旧工艺来说，这种关系几乎线性；对 32 nm 及以下工艺，会表现出非线性。

    Input slew 表示输入边沿的上升/下降时间。输入边沿越慢，NMOS/PMOS 的导通状态变化越慢，输出电容的充放电电流变小，因此门延迟增大。图中 triset_{rise}trise​ 越大，输出高到低延迟 tpHLt_{pHL}tpHL​ 越大。实际 STA 中，单元 delay 不是常数，而是 delay=f(input slew, output load)delay=f(input\ slew,\ output\ load)delay=f(input slew, output load)，所以高速设计必须控制输入 slew。

    tpd≈RCt_{pd}\approx RCtpd​≈RC， 其中：R=MOS 等效导通电阻R=\text{MOS 等效导通电阻}R=MOS 等效导通电阻，C=输出节点总电容C=\text{输出节点总电容}C=输出节点总电容，并且： W↑⇒R↓, C↑W\uparrow \Rightarrow R\downarrow,\ C\uparrowW↑⇒R↓, C↑，所以 sizing 是 trade-off。

    为什么 NOR 比 NAND 差？

    因为 NOR 的 PMOS 是串联的，而 PMOS 本身迁移率低、驱动弱。为了匹配驱动能力，需要把 PMOS 做得更宽，导致输入电容明显增加。

    P79：Derivation —— 最佳级数公式怎么来的？（看看就行，非重点）

    推导最佳级数

    思路是：假设原来的 logic block 有 n1n_1n1​ 级，现在可以在路径末端加 inverter buffer，把总级数变成 NNN。

    总 delay 写成：

    D=NF1/N+∑i=1n1pi+(N−n1)pinvD=NF^{1/N}+\sum_{i=1}^{n_1}p_i+(N-n_1)p_{inv}D=NF1/N+i=1∑n1​​pi​+(N−n1​)pinv​

    其中：

    • NF1/NNF^{1/N}NF1/N 是所有 stage effort delay 的总和；
    • ∑pi\sum p_i∑pi​ 是原始逻辑门的寄生延迟；
    • (N−n1)pinv(N-n_1)p_{inv}(N−n1​)pinv​ 是额外插入 inverter 的寄生延迟。

    为了找最佳 NNN，对 NNN 求导并令导数为 0。

    课件定义：ρ=F1/N\rho=F^{1/N}ρ=F1/N也就是最佳 stage effort。

    最后得到最佳 stage effort 满足：pinv+ρ(1−ln⁡ρ)=0p_{inv}+\rho(1-\ln\rho)=0pinv​+ρ(1−lnρ)=0

    这个公式的作用是告诉我们：最佳每级 effort 不只是数学上的 eee，还要考虑每加一级 inverter 带来的 parasitic delay。

    P80：Best Stage Effort —— 最佳每级 effort 大约是多少？（看看就行，非重点）

    P80 继续 P79 的公式：

    pinv+ρ(1−ln⁡ρ)=0p_{inv}+\rho(1-\ln\rho)=0pinv​+ρ(1−lnρ)=0

    这个方程没有简单解析解。

    如果忽略 parasitic delay：pinv=0p_{inv}=0pinv​=0

    那么：ρ=e≈2.718\rho=e\approx2.718ρ=e≈2.718

    这说明纯数学上，如果只考虑 effort delay，最佳每级放大倍率是 eee。

    但真实 inverter 有寄生延迟。若：pinv=1p_{inv}=1pinv​=1

    数值解得到：ρ=3.59\rho=3.59ρ=3.59

    这就是为什么工程上经常说最优 stage effort 接近 4，也就是 FO4 附近。

    所以实际经验是：f^≈4\hat f \approx 4f^​≈4

    这也是 P83 里用：N=log⁡4FN=\log_4FN=log4​F 估算最佳级数的原因。

    第一步：Compute path effort

    F=GBHF=GBHF=GBH

    第二步：Estimate best number of stages（N已知时不需要）

    N=log⁡4FN=\log_4FN=log4​F

    这里的 4 来自前面最佳 stage effort 接近 FO4。

    如果算出来不是整数，就选附近的整数进行比较。

    如果原路径级数不够，就加 buffer。

    如果原路径级数太多，就考虑改拓扑，减少逻辑级数。

    D=NF1/N+PD=NF^{1/N}+PD=NF1/N+P

    P85：Key Take-Aways —— Logical Effort 的优点和限制

    第一，logical effort 可以用数字表征不同 gate 的速度代价。

    第二，最快路径通常让每一级 effort 接近 4。

    第三，路径 delay 对级数和尺寸不是极端敏感。

    第四，级数少不一定更快。

    第五，在 CMOS 中，NAND 通常比 NOR 快。

    原因是 NOR 的 PMOS 串联，PMOS 本身弱，为了匹配驱动能力需要更大W，输入电容大，所以 logical effort 更大。

    第六，inverter 和 NAND2 通常比较适合驱动大电容。
